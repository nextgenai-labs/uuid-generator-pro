# Support

## Purchased on Codester

If you purchased UUID Generator Pro on Codester, you are entitled to support through the Codester purchase page.

**What is covered:**

- Installation and setup assistance
- Bug verification
- Usage questions

**Response time:** Within 48 hours (business days)

**How to request support:**

1. Log in to your Codester account.
2. Go to your purchases page.
3. Find UUID Generator Pro and click "Contact Author."

## GitHub Issues

You can also open a support issue on the [GitHub repository](https://github.com/nextgenai-labs/uuid-generator-pro/issues).

Please use the `support` label when filing issues.

## Before Contacting Support

- Check [FAQ.md](faq.md) for common questions.
- Review the main [INSTALL.md](../../INSTALL.md) for setup guidance.
- Search existing GitHub issues for solutions.
